🎯 THE PROBLEM:
Your Firestore database security rules are blocking access.
This is a VERY common issue - easy to fix!

═══════════════════════════════════════════════════════════════════════════

✅ THE SOLUTION (Follow These Exact Steps):

STEP 1: Open Firebase Console
─────────────────────────────────────────────────────────────────────────
  1. Open browser
  2. Go to: https://console.firebase.google.com/
  3. Click on your project: "sample-firebase-ai-app-9c94d"

STEP 2: Go to Firestore Rules
─────────────────────────────────────────────────────────────────────────
  1. Look at LEFT SIDEBAR
  2. Click: "Firestore Database" (cloud icon)
  3. At the TOP, click the "Rules" tab
     (You'll see tabs: Data | Rules | Indexes | Usage)

STEP 3: Replace the Rules
─────────────────────────────────────────────────────────────────────────
  1. You'll see a code editor with current rules
  2. SELECT ALL (Ctrl+A or Cmd+A)
  3. DELETE everything
  4. PASTE this code:

┌───────────────────────────────────────────────────────────────────────┐
│ rules_version = '2';                                                  │
│                                                                        │
│ service cloud.firestore {                                             │
│   match /databases/{database}/documents {                             │
│     match /{document=**} {                                            │
│       allow read, write: if true;                                     │
│     }                                                                  │
│   }                                                                    │
│ }                                                                      │
└───────────────────────────────────────────────────────────────────────┘

STEP 4: Publish the Rules
─────────────────────────────────────────────────────────────────────────
  1. Click the blue "Publish" button (top right)
  2. Wait for message: "Rules published successfully"
     (This takes 5-10 seconds)

STEP 5: Test Your App
─────────────────────────────────────────────────────────────────────────
  1. Go back to: http://localhost:5173
  2. Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
  3. Click the "السجل" (History) button
  4. ✅ Error should be GONE!

═══════════════════════════════════════════════════════════════════════════

🎉 HOW TO VERIFY IT WORKED:

Method 1: Check Browser Console
  1. Press F12 (or Cmd+Option+I on Mac)
  2. Click "Console" tab
  3. Look for:
     ✅ Firebase initialized successfully
     ✅ Loaded X ideas from Firestore
  4. Should NOT see:
     ❌ Missing or insufficient permissions

Method 2: Test in App
  1. Generate a video script (enter idea, click button)

❓ STILL HAVING ISSUES?

Issue: Rules editor shows error "Invalid syntax"
  → Make sure you copied the ENTIRE rule (including first and last lines)
  → Check for extra characters or missing brackets

Issue: Publish button is grayed out
  → Wait a moment, it enables when page fully loads
  → Try refreshing the Firebase Console page

Issue: Still getting permissions error after publishing
  → Wait 30 seconds for rules to propagate
  → Clear browser cache completely
  → Close and reopen browser
  → Make sure you're on the correct Firebase project

Issue: Different error message appears
  → Read FIREBASE_PERMISSIONS_FIX.md for detailed troubleshooting
  → Check your Firebase config in src/config/firebaseConfig.js
