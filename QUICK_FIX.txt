📝 STEP 1: Configure Firebase (5 minutes)
═══════════════════════════════════════════════════════════════════════════
1. Go to: https://console.firebase.google.com/
2. Create new project → Name it "video-script-generator"
3. Click "Firestore Database" → "Create database" → "Test mode"
4. Go to Project Settings (⚙️) → Scroll to "Your apps" → Click </> icon
5. Copy the firebaseConfig values
6. EDIT THIS FILE: src/config/firebaseConfig.js
   Change THIS:
   ┌────────────────────────────────────────────────────────────┐
   │ apiKey: "YOUR_FIREBASE_API_KEY",                           │
   │ authDomain: "your-project.firebaseapp.com",                │
   │ projectId: "your-project-id",                              │
   └────────────────────────────────────────────────────────────┘
   To YOUR REAL VALUES (from Firebase console):
   ┌────────────────────────────────────────────────────────────┐

   │ authDomain: "video-scripts-xyz.firebaseapp.com",           │
   │ projectId: "video-scripts-xyz",                            │
   └────────────────────────────────────────────────────────────┘
═══════════════════════════════════════════════════════════════════════════
📝 STEP 2: Configure OpenRouter (3 minutes)
═══════════════════════════════════════════════════════════════════════════
1. Go to: https://openrouter.ai/
2. Sign in with Google/GitHub
3. Go to: https://openrouter.ai/keys
4. Click "Create Key" → Name it → Copy the key (starts with sk-or-v1-)
5. Go to: https://openrouter.ai/credits → Add $5
6. EDIT THIS FILE: src/config/openRouterConfig.js
   Change THIS:
   ┌────────────────────────────────────────────────────────────┐
   │ apiKey: "YOUR_OPENROUTER_API_KEY",                         │
   └────────────────────────────────────────────────────────────┘
   To YOUR REAL API KEY:
   ┌────────────────────────────────────────────────────────────┐
   │ apiKey: "sk-or-v1-abc123def456ghi789jkl012mno345...",      │
   └────────────────────────────────────────────────────────────┘

📝 STEP 3: Restart the Server
═══════════════════════════════════════════════════════════════════════════
In terminal:
  1. Press Ctrl+C (to stop current server)
  2. Run: npm run dev
  3. Open: http://localhost:5173/

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════
Still loading forever?
  → Check F12 console for error messages
  → Make sure you SAVED the config files after editing
  → Clear browser cache: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

🔒 Firebase Permissions Error?
  Error: "Missing or insufficient permissions"
  FIX → Read: FIREBASE_PERMISSIONS_FIX.md
  Quick Fix:
    1. Go to Firebase Console → Firestore Database → Rules
    2. Paste these rules:
       ┌────────────────────────────────────────────────────────┐
       │ rules_version = '2';                                   │
       │ service cloud.firestore {                              │
       │   match /databases/{database}/documents {              │
       │     match /{document=**} {                             │
       │       allow read, write: if true;                      │
       │     }                                                   │
       │   }                                                     │
       │ }                                                       │
       └────────────────────────────────────────────────────────┘
    3. Click "Publish"
    4. Refresh your app (Ctrl+Shift+R)
